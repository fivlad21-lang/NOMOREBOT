# ТЗ — копірайт: фокус «зробиш саме сайт»

**Статус:** застосовано в коді (2026-07-24)

## Позиціонування
Ти сам зробиш **сайт під свої потреби** за вечір — структура, тексти, запуск, правки без агентства.  
Соцмережі лише як `?from=` (канал входу), не як суть оферу.

## Ключові заміни
- H1: «Зроби сайт під свої потреби за вечір.»
- Proof / CTA / footer / modules / expert / FAQ / OG — без TikTok / воронки / трафіку як головного меседжу
- Checkout / thanks / оплата **курсу** — без змін логіки
