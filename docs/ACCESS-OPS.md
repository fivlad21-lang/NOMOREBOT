## Чекліст продавця на кожен продаж

### Start / Community
1. Перевірити лог Approved або thanks у клієнта  
2. Якщо людина пише «немає доступу» — звірити orderId, статус WFP, надіслати правильний інвайт вручну  
3. Community: переконатись, що зайшла і в канал, і в групу  

### Mentor
1. Чекати DM з шаблоном / номером замовлення  
2. Відкрити особистий чат менторства  
3. Зафіксувати: старт 14 днів, слоти 2 дзвінків, дата розбору ленду  
4. Вести лічильник місць (`MENTOR_SEATS = 8`) вручну  

### Ескалації
| Симптом | Дія |
| --- | --- |
| Approved, але thanks fail | `/api/pay/status?order=` + Redis health |
| Сплатив, інвайт не відкривається | видати запасний інвайт / додати вручну |
| Хоче повернення | оферта §4, перевірити % матеріалів |
